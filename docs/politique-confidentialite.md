# Politique de confidentialité de Ruella

Dernière mise à jour : 28 octobre 2026.

Ruella est une application de visite de villes. Elle est conçue pour fonctionner **sans compte et sans serveur** : vos données restent sur votre téléphone.

## Données enregistrées sur votre téléphone

- Vos séjours (ville, dates, étapes, point de départ).
- Les étapes cochées et leur heure, d'où découlent points, badges et tampons.
- Les prénoms (facultatifs) et tranches d'âge des voyageurs, utilisés pour choisir les visites. Aucun compte enfant.
- Vos réglages (thème, rythme, notifications, validation sur place).

Rien de tout cela n'est transmis à Ruella ni à un tiers.

## Position

Avec votre accord, l'application utilise votre position **uniquement pendant qu'elle est ouverte** pour afficher votre point sur la carte, partir de l'endroit où vous êtes, et cocher une étape quand vous y arrivez (option désactivée par défaut). La position n'est ni enregistrée ni envoyée. Aucune localisation en arrière-plan.

## Notifications

Le programme du matin est programmé localement par le téléphone. Aucun serveur de notification n'est utilisé.

## Ce qui passe par Internet

- Les photos des lieux, téléchargées depuis Wikimedia Commons.
- Les mises à jour de l'application (Expo Updates), qui ne contiennent aucune donnée personnelle.
- Le bouton « Y aller » ouvre Plans (Apple) ou Google Maps, soumis à leurs propres politiques.

## Ni publicité, ni pistage

Aucune publicité, aucun outil d'analyse d'audience, aucun traceur, aucune statistique d'usage.

## Vos droits

Profil › Exporter mes données vous remet l'ensemble de vos données. Profil › Tout effacer les supprime définitivement ; désinstaller l'application aussi.
